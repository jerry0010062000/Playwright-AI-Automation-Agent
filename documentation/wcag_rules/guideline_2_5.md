## ⚙️ Rules details

### Success Criterion 2.5.1 - Pointer Gestures (Level A)

> (Level A)

> All functionality that uses multipoint or path-based gestures for operation can be operated with a single pointer without a path-based gesture, unless a multipoint or path-based gesture is essential.

> This requirement applies to web content that interprets pointer actions (i.e., this does not apply to actions that are required to operate the user agent or assistive technology).

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-1-pointer-gestures)

---

### Success Criterion 2.5.2 - Pointer Cancellation (Level A)

> (Level A)

> For functionality that can be operated using a single pointer, at least one of the following is true:

> Functions that emulate a keyboard or numeric keypad key press are considered essential.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-2-pointer-cancellation)

---

### Success Criterion 2.5.3 - Label in Name (Level A)

> (Level A)

> For user interface components with labels that include text or images of text, the name contains the text that is presented visually.

> A best practice is to have the text of the label at the start of the name.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-3-label-in-name)

---

### Success Criterion 2.5.5 - Target Size (Enhanced) (Level AAA)

> (Level AAA)

> The size of the target for pointer inputs is at least 44 by 44 CSS pixels except when:

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-5-target-size-enhanced)

---

### Success Criterion 2.5.6 - Concurrent Input Mechanisms (Level AAA)

> (Level AAA)

> Web content does not restrict use of input modalities available on a platform except where the restriction is essential, required to ensure the security of the content, or required to respect user settings.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-6-concurrent-input-mechanisms)

---

### Success Criterion 2.5.7 - Dragging Movements (Level AA)

> (Level AA)

> New

> All functionality that uses a dragging movement for operation can be achieved by a single pointer without dragging, unless dragging is essential or the functionality is determined by the user agent and not modified by the author.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-5-7-dragging-movements)

---
