## ⚙️ Rules details

### Success Criterion 2.4.1 - Bypass Blocks (Level A)

> (Level A)

> A mechanism is available to bypass blocks of content that are repeated on multiple web pages.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-1-bypass-blocks)

---

### Success Criterion 2.4.2 - Page Titled (Level A)

> (Level A)

> Web pages have titles that describe topic or purpose.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-2-page-titled)

---

### Success Criterion 2.4.3 - Focus Order (Level A)

> (Level A)

> If a web page can be navigated sequentially and the navigation sequences affect meaning or operation, focusable components receive focus in an order that preserves meaning and operability.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-3-focus-order)

---

### Success Criterion 2.4.4 - Link Purpose (In Context) (Level A)

> (Level A)

> The purpose of each link can be determined from the link text alone or from the link text together with its programmatically determined link context, except where the purpose of the link would be ambiguous to users in general.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-4-link-purpose-in-context)

---

### Success Criterion 2.4.5 - Multiple Ways (Level AA)

> (Level AA)

> More than one way is available to locate a web page within a set of web pages except where the web page is the result of, or a step in, a process.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-5-multiple-ways)

---

### Success Criterion 2.4.6 - Headings and Labels (Level AA)

> (Level AA)

> Headings and labels describe topic or purpose.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-6-headings-and-labels)

---

### Success Criterion 2.4.7 - Focus Visible (Level AA)

> (Level AA)

> Any keyboard operable user interface has a mode of operation where the keyboard focus indicator is visible.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-7-focus-visible)

---

### Success Criterion 2.4.8 - Location (Level AAA)

> (Level AAA)

> Information about the user's location within a set of web pages is available.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-8-location)

---

### Success Criterion 2.4.9 - Link Purpose (Link Only) (Level AAA)

> (Level AAA)

> A mechanism is available to allow the purpose of each link to be identified from link text alone, except where the purpose of the link would be ambiguous to users in general.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-9-link-purpose-link-only)

---

### Success Criterion 2.4.10 - Section Headings (Level AAA)

> (Level AAA)

> Section headings are used to organize the content.

> "Heading" is used in its general sense and includes titles and other ways to add a heading to different types of content.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-10-section-headings)

---

### Success Criterion 2.4.11 - Focus Not Obscured (Minimum) (Level AA)

> (Level AA)

> New

> When a user interface component receives keyboard focus, the component is not entirely hidden due to author-created content.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-11-focus-not-obscured-minimum)

---

### Success Criterion 2.4.12 - Focus Not Obscured (Enhanced) (Level AAA)

> (Level AAA)

> New

> When a user interface component receives keyboard focus, no part of the component is hidden by author-created content.

- [W3C Spec Link](https://www.w3.org/TR/WCAG22/#x2-4-12-focus-not-obscured-enhanced)

---
